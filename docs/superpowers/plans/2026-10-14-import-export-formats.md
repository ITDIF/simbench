# 多种导入导出格式 + 协议适配器（评估与落地）

日期：2026-10-14　｜　范围：**格式那半边落地**（格式表 + Excel 读写）；**协议那半边给结论**
（适配器已经有了，缺的是"注册"），并附"加一种协议要改哪几处"的实测清单。

> 起因是用户的两个问题："新增多种导入导出的格式"与"有一个协议适配器会不会更好"。
> 前者的答案是"做"，后者的答案是"已经是这个形状了，但要按需再抽一层注册表"。

---

## 1. 现在的事实（实测，不是推测）

**格式那半边：没有抽象。** `.json` 与"其余按 CSV"这套分派原来在**四处**各写一遍
（`csv_io_entry.load_point_table`、`dialogs.open_project` / `save_project_to` /
`save_project_as`），外加三个文件对话框的过滤器字符串——**加一种格式要改六处**，漏一处的
表现是"打开能读、保存却写成了另一种格式"。

**协议那半边：适配器已经有了。** 结构上三件事把它撑住了：

| 位置 | 作用 | 证据 |
|---|---|---|
| `project/model.channel_transport()` | **唯一**的"这一路是什么传输"判据 | 全包 13 个文件、29 处都在问它，没有第二套 isinstance 判定 |
| `backend.make_backend()` | **唯一**的装配口（按传输选后端） | 界面、命令行、会话三条路都走它 |
| `backend/modbus_base.ModbusBackendBase` 的钩子 | 与传输无关的那一半（波形 tick、值归属、报文/日志钩子、启停顺序） | S7 落地时只填了 8 个钩子，**Modbus 两条路的既有用例一个断言没改** |

所以"要不要一个协议适配器"这个问题，答案是：**它已经在了**（S7 就是照它接上去的）。
真正还缺的是**"注册"**——每种协议的事实（通道类、区/类型清单、默认区、默认点位类型、
名字语法、校验函数）散在 15 个文件里各写一遍 if/elif：

```
按传输分叉的地方（实测数出来的，2026-10-14）：
  channel_transport 判定      29 处 / 13 个文件   ← 好：大家都问同一个判据
  isinstance 到通道类          4 处 /  2 个文件
  布尔 s7 标志                27 处 /  3 个文件   ← 真正的卡点（见下）
  "s7"/"rtu"/"tcp" 字面量比较  45 处 / 15 个文件
  默认区/类型/区清单           51 处 / 13 个文件
```

**其中一处是硬卡点**：`engine/session.py` 与 `project/edit.py` 用**布尔 `s7`** 表示传输
（`_render(pt, regs, s7)`、`_span_of(pt, s7)`、`next_point_address(..., s7)`）——第四种协议
**加不进来**，因为布尔只有两态。这一处必须改成传输串（本轮已做，见 §3）。

## 2. 口径

| # | 要定的事 | 结论 |
|---|---|---|
| 1 | 格式怎么登记 | **一张表**：`Format(后缀, 对话框里那一行文字, 读, 写, kind)`；读回 `(Project, notes)`，写按后缀分派。加格式 = 加一行 + 一个模块 |
| 2 | 后缀不认识怎么办 | **拒绝**（`FormatError`，`ValueError` 的子类）并把支持哪些写进消息——猜一个格式等于把 JSON 当 CSV 解析 |
| 3 | Excel 怎么读 | **转成 CSV 文本再交给同一个解析器**：通道名里的 `@tcp:host:port` 语法、端口"猜了要说"、逐行/带行号的报错一个字都不重写，两边语义也不可能漂 |
| 4 | 表头不在第一行 | **找**第一行与表头 12 格完全一致的行，并用**空行补齐**前面几行——报错里的"第 N 行"因此与 Excel 里看到的一致；找不到就原样交给 `csv_io` 报它那句 `header mismatch` |
| 5 | 单元格的数字 | 只把**逐字往返相同**的按数字写（`str(int(t)) == t`），`0008`/`12.50`/`1e5` 一律落成文本——否则 Excel 一存就静默改点表 |
| 6 | Excel 存不下的数 | 17 位 uint64（累计电量那种）**读进来时**若发现那一格是数字，给一条 note 点明"Excel 只有 15 位有效数字"；**写出去时**把它写成文本格（逐字往返） |
| 7 | 协议那半边现在抽不抽注册表 | **不抽**，但把布尔 `s7` 改成传输串（历史包袱，不抽就加不了第四种协议）；等第四种协议**真的来了**、知道它的形状之后再按它定表——在那之前抽出来的会是一层用不上的间接，还要改 15 个文件去用它 |
| 8 | 加一种协议要动哪儿 | 写成清单（§4），下一份计划照着它走 |

## 3. 任务

### Task 1　格式表（`project/formats.py`）
`FORMATS` / `format_for` / `read_project` / `write_project` + 三个过滤器
（打开 / 另存为 / 只导出点表）。四个分派点与三个过滤器字符串全部改走它；界面的"导出"
那条也从固定的 `write_csv_file` 改成 `write_project`——**后缀说了算**（见 D1）。

### Task 2　Excel 读写（`project/xlsx_io.py`）
`sheet_rows`（读成二维字符串表，空行与行号都留）、`read_xlsx_file`（找表头 + 补空行 +
交给 `csv_io`）、`write_xlsx_file`（用 `csv_io.rows_of` 的同一个行形状 + 冻结表头 + 列宽）；
数字格丢精度时给 note。

### Task 3　把布尔 `s7` 改成传输串
`engine/session.py`：`_render` / `_span_of` / `_source_of` / `_read_back` / `_snapshot*` /
`_is_s7` → 传输串；`project/edit.py`：`next_point_address` / `_point_span` / `_occupied_end` /
`default_point` → 传输串。**行为一个字不变**（既有用例逐条证明），但第四种协议不再被两态挡住。

### Task 4　测试与文档
`tests/test_formats.py`（格式表 + 三种格式往返 + Excel 的现场形状 + 两个界面入口）；
`packaging/smoke.py` 加一条"冻结包里也能读 .xlsx"（验 openpyxl 真进包了）；
spec §5 / README / requirements。

## 4. "加一种协议要改哪几处"（清单，给下一份计划）

1. `project/model.py`：一个新的通道 dataclass + `channel_transport()` 加一条 + 名字语法（若有）；
2. `project/validate.py`：一个 `_新协议(ch, issues, where)`，并在 `validate_project` 的分派里挂上；
3. `project/csv_io.py`：通道名那一格的写法（解析 + 渲染各一条）；
4. `project/edit.py`：`TRANSPORTS` + 默认通道 + 默认区/默认点位类型；
5. `backend/`：一个新后端（照 `ModbusBackendBase` 的钩子填）+ `make_backend` 加一条；
6. `codec/`：点位值 ↔ 字节（若协议自己的编码不同）；
7. `engine/session.py`：读写分派（按传输串，不再用布尔标志）；
8. `net/endpoints.py`：主站该连哪个地址（TCP 类才有）；
9. 界面三处：通道面板那一行的三格、`ChannelForm` 的标签/提示、属性面板的区与类型选项；
10. `gui/point_table.py`：原始寄存器那一列怎么打（寄存器 / 字节 / 别的）。

**16 处**，其中 5 处（1/2/5/7/8）是"必须"，其余是界面与语法的呈现。

## 4b. 执行期已裁决的偏离（D1–D3）

| # | 计划里写的 | 实际做的 | 为什么 |
|---|---|---|---|
| D1 | 四个分派点改走格式表 | **多一个**：界面"导出"那条（原来固定 `write_csv_file`）。现在走 `formats.write_project`，后缀说了算 | 导出对话框的过滤器里有 Excel 那一行；选了 Excel 却写 CSV 字节，Excel 打开一句"文件格式不对" |
| D2 | 界面文字不动 | 工具栏/菜单那两个字：「导入CSV / 导出CSV」→「**导入点表 / 导出点表**」（快捷键与动作对象不变） | 加了 Excel 之后"CSV"这两个字已经是假的；用例同步改了两处断言，并新增一条"选 .xlsx 就真写 Excel" |
| D3 | §2 口径 7："协议那半边**不抽**注册表" | 照旧不抽，只把布尔 `s7` 换成传输串 | 计划就是这么定的，记一条免得下次又从头纠结 |
| D4 | 导出沿用老行为（有工程路径就**就地**写一份 CSV，不问） | 改成**每次都问落到哪**，默认名 = 工程旁边那份 `.csv` | 不问就配不上「选格式」这件事：对话框里明明是两种点表，有路径就直接写等于这个按钮只能出 CSV，要 Excel 得绕道「另存为」——而那一动会把 Ctrl+S 的落点也换成点表文件。默认名 + 回车 = 老行为，成本是一次回车 |
