重新生成：`regenerate.py`（**别**设 `QT_QPA_PLATFORM=offscreen`，那套兜底字体的字距不是
现场的；脚本会在有桌面的机器上真开一下窗口、抓完就关）。

**它抓到过的两处**（都已修，且都有断言钉住）：

1. 表单提示那一格 190px 装不下"串口名要自己填：本工具不替现场猜 COM 口"（要 240px）——
   Qt 不接省略号，屏幕上就是硬切掉半句，而那句话正是要人看见的；
2. 设备对话框的 `unit id` 标签要 91px、塞进 84px 的槽——显示成 `unit i…`。

两处现在都由 `tests/test_gui_new_project.py::test_every_fixed_slot_in_the_forms_fits_its_longest_caption`
按 `fontMetrics` 逐个槽量住（主窗那一套同形断言见 `tests/test_gui_theme.py`）。
